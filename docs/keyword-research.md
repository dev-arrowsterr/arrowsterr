# Keyword Research: match types

The full keyword list ("View all" on a keyword's ideas) works like Semrush's Keyword Magic Tool.

## Match types
| | What it finds | DataForSEO Labs call |
|---|---|---|
| Broad match | Every word of the seed, any order, any form ("tools" finds "tool") | `keyword_ideas`, one `like` filter per word (up to 4) |
| Phrase match | The seed's words in order, other words around them | `keyword_suggestions` |
| Exact match | The seed as whole words, same order and form | `keyword_suggestions` with a whole-word regex |
| Related | Same meaning, other words | `related_keywords`, 3 steps out |

- **Questions** switch: adds the question regex (what, how, why...) to any match type.
- **Include and exclude words:** run in the browser on the loaded list, so they cost nothing.
- **Word groups:** on the left, by how many keywords share each word. Click one to narrow the list.
- **Totals:** keywords, searches a month and average KD for what is showing.
- **Export CSV:** exports what is showing.
- **Saving and sharing:** each list is up to 1,000 keywords by volume. Lists are saved for 30 days and shared across workspaces, so a repeat is free. The match type is in the address (`&match=broad`).
- **Tasks:** a list costs 10 tasks, like any keyword search.
